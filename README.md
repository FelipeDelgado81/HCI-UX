# HCI-UX
 
La app se trata de una aplicaccion para notificar casi accidentes en la universidad de la frontera. 
La prevención depende de que se reporten los incidentes sin daño, pero el trabajador o estudiante teme la sanción y el reporte compite con el ritmo de la faena. Debe diseñar una captura de pocos segundos, con anonimato configurable, y una interfaz que haga creíble la promesa de no punición; de lo contrario el sistema recibe cero reportes aunque funcione perfectamente.
